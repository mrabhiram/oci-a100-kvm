# Contributing

Open a pull request with the problem, change and checks performed.

Keep examples free of credentials, customer data and real host inventories. Use the configuration file for values that vary by host. Preserve device ownership checks, protected backups and recovery guards.

Run the checks in [test/README.md](test/README.md). State whether hardware testing was performed. CI runs offline checks only; GPU or reboot tests need an authorized lab.

Contributions are provided under the [MIT license](LICENSE).
